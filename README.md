## Project Concept

후방 깊은 위치에서 경기 흐름을 읽고 공격을 설계하는 축구 포지션인 **Regista(레지스타)**의 역할을 문제 해결 방식(분석 → 설계 → 구현)에 투영했습니다.

- **히어로 화면**: 세로형 고각 경기장 야경을 통한 시각적 집중도 확보
- **스크롤 전환**: 캔버스 서브픽셀 다운샘플링 기반 픽셀 아트 도트화 및 3D 이젤 전술판 전환
- **인터랙션**: 11명 선수 마커의 실제 축구 전술 동선(공격 압박, 라볼피아나 빌드업, 오버래핑) 및 글래스모피즘 상세 설명 카드 연동

## Vibe Coding & Engineering Log

AI를 단순 코드 자동완성 도구가 아닌 페어 프로그래머로 활용하며, 추상적인 시각적 인상을 구체적인 프론트엔드 규격으로 구현했습니다.

### 1. 추상적인 감각을 구체적인 기술 규격으로 전환
- **고해상도 도트 게임 질감**: 이미지를 단순 블러 처리하지 않고, 오프스크린 캔버스를 이용한 정수 배율 다운샘플링과 CRT 스캔라인 그리드 오버레이를 조합해 질감을 살렸습니다.
- **이젤에 누운 전술판 연출**: CSS `perspective`와 `rotateX(24deg)`를 이용한 사다리꼴 변형, 좌/우 2열 분할 배치를 적용해 마커가 설명 카드에 가려지지 않도록 설계했습니다.

### 2. AI 제안 검증 및 도메인 기반 의사결정
- **실제 축구 전술 메커니즘 직접 반영**: 6번 레지스타의 딥라잉 피벗 롤, 빌드업 시 3백 사이 하강(라볼피아나), 풀백 오버래핑 시 윙어의 박스 안 투톱 쇄도 등 실제 전술 구조를 직접 정의하고 마커 좌표계를 교정했습니다.
- **불필요한 기술적 복잡도 배제**: AI가 초기에 제안한 WebGL 3D 카메라 앵글 회전 대신 순수 Canvas 줌인 크롭을 선택해 렌더링 성능과 브라우저 호환성을 확보했습니다.
