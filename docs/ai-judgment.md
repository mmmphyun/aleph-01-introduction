# AI와 나의 판단 — T01

## 1. AI에게 맡긴 일

- 과제 안내 5페이지 브라우저로 수집·정리
- 단계별 질문 구성 및 진행 (1단계: 대상·공개범위 / 2단계: 상황·행동·결과 구조화)
- 공개·비공개 항목 초안 작성 및 과제 기준 대조
- 킬러포트폴리오 레퍼런스 사이트 조회 및 후보 정리
- 포지션(스트라이커·볼란치·풀백)과 섹션 매핑 초안 제안
- 전체 구현 계획서 문서화

## 2. 직접 판단한 일

- 기술 스택을 Vanilla HTML/CSS/JS + GitHub Pages로 확정
  (프레임워크 없이도 과제 요건 충족 가능하다고 직접 판단)
- 히어로에서 실제 경기장처럼 착각하게 만드는 연출 방향 제안
  (AI는 CSS 그라디언트 경기장을 제안했으나, 사진으로 현실감을 줘야 한다고 직접 결정)
- Regista 닉네임을 소개 문구에 축구 포지션 의미로 활용하기로 결정
- 스트라이커·볼란치·풀백 세 포지션을 직접 선택
- 도트 그리드를 전술판 이후 구간에만 적용하기로 직접 결정

## 3. AI 제안을 따르지 않은 일

- 3D 카메라 앵글 전환 컨셉 제외
  AI가 "바닐라로 가능하다"고 했으나, 4~5시간 예산 안에서
  텍스트 가독성과 과제 기준 충족이 어렵다는 설명을 듣고
  탑뷰 전술판 컨셉으로 직접 전환 결정

- 시간대 전환 연출(낮→석양→야간) 제거
  초기 계획은 AI와 함께 구상했으나 히어로 실사 사진 + 전술판 반전 컨셉으로
  바뀌면서 불필요해져 직접 제외

- 히어로 높이 제한 방식(B안) 대신 하단 스트립(A안) 선택
  AI가 두 가지를 모두 제시했고, 풀스크린 연출을 유지하는 A안을 직접 선택
